INT 2D - lDOS TSRs - GET CTRL2
	AH = AMIS multiplex number
	AL = 22h
Return:	AL = size of returned ctrl2
	DX:BX -> control data
Notes:	ctrl2 has different uses among the TSRs.
	FreeDOS share: ctrl2 is 4 WORDs
		WORD 00h: file_table_size
		WORD 02h: file_table_free
		WORD 04h: lock_table_size
		WORD 06h: lock_table_free
	older revisions of FreeDOS share may return AL = FFh,
		BX = file table size
		CX = file table free
		SI = lock table size
		DX = lock table free
	TSR example: this call is not supported
	RxANSI: this call is not supported
	lClock: this call is not supported
	SEEKEXT: this call is not supported
	KEEPH0OK: this call is not supported
	FDAPM IDLEDPMS: this call is not supported
	EIDL: this call is not supported
	INTERCEP/INTERC3: this call is not supported
	D2FCBFIX: this call is not supported
	SRDISK: this call is not supported
	FDAPM: this call is not supported
	lDebug: this call is not supported
	Loader: this call is not supported
	lDOS kernel: this call is not supported
	LBACACHE: ctrl2 is 14h, 1Eh, or 20h BYTEs
		--- STAT statistics reset by uncache ZERO ---
		DWORD 00h: read hits
		DWORD 04h: read misses
		DWORD 08h: write hits
		DWORD 0Ch: write misses
		--- debugging hints and uncache INFO and TABLE info ---
		(These variables are informational, changing them is not
		 supported and they should be treated as constants.)
		WORD 10h: offset of main cache table (typically ~ 1000h)
		BYTE 12h: log2 of cache table entry size (3)
		BYTE 13h: log2 of how many sectors per entry (0..4)
		--- new TABLE details ---
		DWORD 14h: amount of sectors (to be) allocated in XMS
		DWORD 18h: amount of table entries, should not be changed
			currently because of hidden table size variables
		WORD 1Ch: table format sequential (0)
		--- bonus table details ---
		WORD 1Eh: amount of bonus table entries (after table)
